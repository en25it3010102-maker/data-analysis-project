# Olympic Games Data Analysis

## Project Overview

Olympic Games Data Analysis is a data visualisation project developed using Tableau Public. It explores Olympic medal records across sports, teams, genders, seasons, years, and host cities.

The project transforms the dataset into visualisations, an interactive dashboard, and a Tableau Story to make comparisons and trends easier to understand.

## Objectives

- Analyse Olympic medal-record distributions across different sports.
- Compare medal records across Olympic teams.
- Explore medal-record trends over time.
- Compare medal records by gender and season.
- Identify cities with the highest recorded medal totals.
- Present findings through a Tableau dashboard and Story.

## Dataset

Dataset source: https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results

The analysis is based on the fields available in the source dataset. Results should be interpreted within the dataset's scope and definitions.

## Key Findings
1. The dashboard compares Olympic medal records across sports, teams, genders, seasons, and host cities.
2. The time-series visualisation helps identify changes in recorded medal results across Olympic years.
3. The gender comparison highlights the distribution of medal records between male and female athletes.
4. The seasonal comparison shows how medal records are distributed between Summer and Winter Olympics.
5. The sport-wise analysis helps compare recorded medal results across different sports.
